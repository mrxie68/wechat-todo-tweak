# 微信待办事项插件（Memos 联动）

在微信里造一个"待办事项"联系人，像聊天一样记待办，本地存储为主，可同步到自己的 Memos 服务器。

## 功能
- 聊天列表出现"待办事项"联系人（本机假联系人，不会同步到电脑/其他设备）
- 直接发文字 = 记一条待办；命令式管理：
  - `待办` / `列表`：查看未完成
  - `完成 1` / `取消 1` / `删除 1`：按编号管理
  - `历史`：查看全部记录
  - `同步`：把未完成待办推到 Memos
  - `帮助`：显示用法
- 本地存储为主（秒回、离线可用），Memos 镜像同步（配置地址 + Token 后可推）
- 支持 IPv6 地址（Memos 地址填 `http://[2001:db8::1]:5230` 这种格式）

## 使用
1. GitHub Actions 编译出 `wechat-todo.dylib`，TrollFools 注入微信
2. 我的 → 插件页面 → 待办事项，配置 Memos 地址/Token
3. 点"创建/检查待办联系人"，聊天列表出现"待办事项"
4. 开始聊天式记待办
