# 微信待办事项插件（Memos 联动）

在微信主界面底部向上滑动，呼出一个全屏待办页，像普通待办 App 一样记录。本地存储为主，可同步到自己的 Memos 服务器。

## 功能
- 微信主界面底部中间有个「⬆ 待办」小按钮，点击或从底部向上滑都能打开待办页
- 待办页像原生待办 App：底部输入添加、点击勾选/取消、左滑删除、待办/已完成/全部三档筛选
- 按微信账号隔离数据（两个微信号互不串用）
- Memos 镜像同步：配置地址 + Token 后，新增/完成时后台自动推送未完成项
- 支持 IPv6 地址（Memos 地址填 `http://[2001:db8::1]:5230` 这种格式）

## 使用
1. GitHub Actions 编译出 `wechat-todo.dylib`，TrollFools 注入微信
2. 微信主界面底部向上滑动，进入待办页
3. 设置页（我的 → 插件 → 待办事项）配置 Memos 地址/Token/可见性，也可以从这里打开待办页

## 说明
- v0.2.0 起不再使用 `todo@local` 假联系人，首次启动会自动清理旧版残留的假联系人，无需手动操作
- 本地待办不依赖微信服务器，卸载插件后数据仍留在本机（NSUserDefaults，按账号隔离）
